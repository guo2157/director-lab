## 修改方式

画面与声音是分开的两条链，互不影响：

```bash
# 只改解说
python vo.py          # 逐句合成（结果缓存到 audio/vo/），并打印时长槽位表
python audio_vo.py    # 重铺解说、闪避、混音 → audio/mix.wav
ffmpeg -y -i video_silent.mp4 -i audio/mix.wav -map 0:v -map 1:a \
  -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p \
  -vf "fade=t=out:st=74.15:d=1.05" \
  -c:a aac -b:a 192k -af "loudnorm=I=-16:TP=-1.5:LRA=9" -shortest director-lab-intro.mp4

# 只改画面（会触发整片重渲染，约 5 分钟）
node frames.js
```

`promo/index.html` + `promo/render.js` 是逐帧可控的动效页（`window.render(t)`），场景时间表在 `render.js` 顶部的 `S` 对象里，单位秒。改画面时间会让解说错位，需同步改 `vo.py` 的 `LINES`。
