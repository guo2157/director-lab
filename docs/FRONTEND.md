# FRONTEND —— 前端设计规范（唯一权威源）

> 本文档是前端页面、样式与交互的唯一权威定义，由原第 13 章（前端设计）与第 19 章（UI 视觉稿）合并去重而成。接口字段见 API.md，镜头状态语义见 ARCHITECTURE.md。

## 1. 技术栈与状态管理边界

技术栈：Vue 3 + Vite + TypeScript；Naive UI；Vue Router；Pinia；TanStack Query；vue-draggable-plus；ArtPlayer；SSE。

| 存放位置 | 内容 |
| --- | --- |
| Pinia | 当前选中项目、拖拽临时顺序、用户偏好、表单草稿 |
| 查询库（TanStack Query） | 项目列表、分镜列表、资产列表、任务状态、生成结果 |

服务端数据一律走查询库，不放入全局状态。

## 2. 设计原则

| 原则 | 说明 |
| --- | --- |
| 深色为默认 | 创作者长时间使用，且大量预览图像与视频，深色背景能降低画面干扰、减少视觉疲劳 |
| 内容优先 | 界面元素退让，缩略图与视频占主导面积，避免装饰性元素抢占注意力 |
| 状态可见 | 每一张卡片都必须能一眼看出处于哪个生成阶段，不依赖点击进入 |
| 操作就近 | 与某个镜头相关的操作，全部收敛在该镜头卡片及其抽屉内，不跳跃页面 |
| 危险可逆 | 破坏性操作必须二次确认并展示影响范围，优先提供回滚路径 |

## 4. 全局框架

整体框架由四部分组成，尺寸固定如下：

| 区域 | 尺寸 | 内容 |
| --- | --- | --- |
| 顶栏 | 高 56px | Logo、项目面包屑、全局任务入口（含进行中角标）、设置、用户 |
| 左侧栏 | 宽 220px，折叠后 64px | 制作导航：剧本 / 资产库 / 分镜图 / 分镜看板 / 合成与导出（D-23 后分镜图独立成环节），底部任务入口与项目状态指示 |
| 主内容区 | 自适应 | 随页面变化 |
| 右侧抽屉 | 宽 480px | 任务详情、资产详情、镜头详情 |

**顶栏**
- 全局任务入口显示进行中任务数量，有任务时图标带呼吸动效
- 面包屑在项目内页面显示项目名，可点击返回列表

**左侧栏**
- 制作导航（2026-10-27 修订，D-23）：剧本（内含 保存→评估→解析 子流程）→ 资产库（公共资产生图）→ **分镜图**（独立环节，资产库节点下）→ 分镜看板（集级视频/提示词）→ 合成与导出。分镜图从资产库分类中剥离为独立菜单，菜单顺序即流程顺序
- 页面流转链（单一出口原则，含两道人审闸口）：解析完成 → 去资产库；公共资产齐全 → 提交人工审核；**审核通过** → 去分镜图；分镜图逐镜生成并**逐镜人工确认**；全部确认 → 去分镜看板生成视频；分镜图+视频就绪 → 去合成导出；禁止跨级跳转
- 两处闸口的前端表现：资产库横幅在未齐全时禁用『审核通过』、未通过审核时禁用『去分镜图』；分镜图页在资产未审核通过时禁用生成按钮、未全部确认时禁用『去分镜看板』
- 评估/解析视觉归属剧本阶段：面包屑显示『剧本 / 评估』『剧本 / 解析』
- 当前页面项左侧有 3px 主色竖条
- 底部显示项目状态，用状态色小圆点加文字
- 折叠后仅保留图标，悬停显示浮层名称
- 折叠触发：支持手动点击折叠按钮切换；视口宽度 <1440px 时自动折叠为纯图标模式

## 5. 页面规范

### 5.1 页面一：项目列表

**布局**：卡片网格，自适应列数，单卡最小宽度 320px，间距 16px。

**顶部工具条**：搜索框（左）、状态筛选胶囊组（全部 / 草稿 / 进行中 / 已完成）、新建项目按钮（右，主色实心）。

**项目卡片结构**（自上而下）

| 区域 | 内容 |
| --- | --- |
| 上部 16:9 | 封面缩略图；无封面时显示渐变占位；右上角叠加状态标签 |
| 中部 | 项目名称，16px，单行截断 |
| 下部 | 进度条与已完成镜头数 / 总镜头数 |
| 底部 | 左侧更新时间，右侧更多菜单 |

**交互**：悬停时卡片上移 2px 并显示阴影；点击进入项目；更多菜单含归档、删除；『复制』为后续版本功能（PRD.md M1-06，P2），本期在菜单中置灰并悬停提示『后续版本提供』，不调用任何接口。

**新建弹窗字段**：项目名称（必填）、画幅比（9:16 / 16:9 / 1:1，卡片式单选）、创作类型（小说改编 / 剧本直出）。

**空状态**：居中插画 + 一句引导 + 新建按钮。

### 5.2 页面二：项目详情 - 分镜看板

**定位（2026-10-25 修订）**：集级资产生成工作台。分镜图/分镜视频/末帧等产物归属于对应集数，不属于公共资产库。页面按『集选择器 → 场景分组 → 镜头卡片』组织。每镜头三步流水：生成分镜图 → 编辑提示词（@角色/@场景/@道具 自动注入参考图）→ 生成分镜视频（H3 VA 主链路）。

**前置校验与就绪度横幅**：公共资产（角色/场景/道具参考图）未齐全时，顶部显示警示横幅并引导返回资产库；分镜图 N/M、视频 N/M 就绪度横幅常驻，全部完成后显示『去合成导出 →』主按钮。

**顶部工具条**：集选择器（第 N 集）、场景筛选下拉、镜头状态筛选、视图切换（看板 / 列表）、批量操作（批量生成 / 批量重做，选中后启用）。批量生成要求选中镜头 ≥3 个（后端少于 3 个返回 400，见 API.md 生成章节）：选中不足 3 个时按钮禁用，悬停提示『批量生成至少选择 3 个镜头，少量镜头请使用卡片上的单镜生成』。

**看板结构**：按场景纵向分组，每个场景一个分组头，组内横向滚动铺镜头卡片。分组头包含场景序号、场景名、镜头数，以及『生成本场景』『重做本场景』两个按钮。

**镜头卡片（宽 220，高 320）**

| 区域 | 内容 | 说明 |
| --- | --- | --- |
| 上部 16:9 | 缩略图 | 未生成时显示骨架占位与提示文字 |
| 右上角 | 状态角标 | 见下表 |
| 中部 | 镜头号 + 台词摘要 | 台词两行截断 |
| 下部 | 时长、引用资产头像堆叠 | 最多显示 3 个，超出显示 +N |
| 空白区 | 提示词首行预览（12px 辅助色，单行截断） | 缩略图与信息区之间的过渡区域，无提示词时留空 |
| 悬停层 | 生成 / 重做 / 编辑 / 详情 | 半透明遮罩，按钮居中 |

**状态角标定义**

| 状态 | 视觉 | 说明 |
| --- | --- | --- |
| 未生成 | 灰色圆点 | 无任务 |
| 排队中 | 蓝色圆点 + 呼吸动效 | 任务已入队 |
| 生成中 | 环形进度 + 百分比 | 有明确进度时显示 |
| 已完成 | 绿色对勾 | 产物可用 |
| 失败 | 红色叹号，悬停浮层显示原因 | 分环境类与配置类 |
| 待审核 | 橙色圆点 + 审核图标 | 音画超容差或一致性 review，需人工放行或重生成 |
| 待重做 | 黄色圆点 | 上游资产变更后标记 |

**拖拽规范**：卡片左上角显示抓手图标；拖拽中目标位置显示虚线占位框；**仅允许同场景内排序**，跨场景拖动时目标组显示禁止光标；排序提交后显示遮罩，服务端确认后落地。

**右侧抽屉（点击卡片打开）**：大图预览（支持缩放）、生图提示词编辑（shot.image_prompt，对应分镜图生成，按 PROMPTS.md 5.1 分段模板展示）、视频提示词编辑（shot.video_prompt，H3 规范：参考图1=前镜末帧、参考图2=本镜分镜图、六项状态枚举、beats 逐拍）、负向提示词、参考槽位清单（只读展示 ref_identity/ref_scene/ref_prop/ref_prev_frame/ref_image 绑定的实体名称；@名称 可解析显示绿色、未解析显示黄色警示）、参数区（尺寸、种子）、生成历史列表（可查看历史产物并回滚为当前）。生成请求携带编辑后提示词（params.prompt 覆盖默认值）；H3 约束前端预校验（length=17n+5、124–362 帧、fps=24、Ref2VA 至少 1 张参考图），后端 422（h3_duration_unrepresentable / h3_reference_required）转为友好提示。

### 5.3 页面三：项目详情 - 资产库

**定位（2026-10-25 修订）**：公共资产生图工作台 + 文件库。解析产出的角色/场景/道具参考图属于**项目级公共资产**（跨集复用），图片按实体名称绑定（asset 关联 character/scene/prop，供提示词 @名称 引用解析与生成槽位注入）。

**布局**：全局左侧栏（220px）+ 右侧主区。主区自上而下：齐全度横幅 → 制作资产区 → 文件库区（分类树 200px + 资产网格归入文件库区）。

**齐全度横幅（D-23 改造后为两条）**：
1. 齐全度横幅：『资产图生成中：N/M 已完成』，全部完成变绿『公共资产图已齐全，请完成人工审核后进入分镜图』，右侧按钮仅保留『返回解析页』。
2. **人工审核横幅**：展示 pending/approved/rejected 三态文案；右侧按钮『审核通过』（未齐全时禁用）、『驳回返工』（未通过时禁用）、『去分镜图 →』（仅 approved 可用）。驳回后文案提示修改或替换资产后重新提交审核。

**制作资产区（新增）**：解析对象 card 网格，三类混排或分组切换。

| 区域 | 内容 |
| --- | --- |
| card 上部 | 资产图缩略图；未生成时显示占位与类型标签 |
| card 中部 | 实体名称 + 绑定标签（如 @林晚，绿底）；描述/外貌关键词单行截断 |
| card 提示词 | 可折叠面板，展示该实体生图提示词（默认收起） |
| card 操作 | 未生成：『生成参考图』按钮（提交后任务中心看进度，成功回写 portrait/baseline/anchor_asset_id）；已生成：绿色『已生成』标签 + 重生成按钮 |

批量操作：顶部『批量生成资产图』（跳过已生成，全部已生成时提示无需提交）。场景 card 额外展示基准图标签；道具 card 展示锚定图标签。三类分别对应生成槽位：角色→ref_identity（portrait）、场景→ref_scene（baseline）、道具→ref_prop（anchor）。

**分类树**：全部 / 角色 / 场景 / 道具，每项后显示数量。分镜图 / 视频 / 音频属集级资产，**已从资产库分类与上传类型中彻底移除**（2026-10-27 修订，D-23），分镜图移至独立的『分镜图』菜单、分镜视频留在分镜看板，资产库只承载项目级公共资产。
**齐全度口径**：道具只统计 `anchor_required=true` 的条目，与后端审核通过时的校验口径保持一致，避免前端显示未齐全但后端判定齐全、导致审核按钮无法点击。

**资产卡片（200×200）**

| 区域 | 内容 |
| --- | --- |
| 上部 | 缩略图；左上角版本徽标（如 v3）；已锁定时右上角显示锁图标 |
| 中部 | 资产名，单行截断 |
| 下部 | 引用次数，如『引用 5 次』 |

**选中态**：卡片边框主色 2px，左上角显示勾选标记，顶部工具条切换为批量操作（导出 / 锁定 / 删除）。

**锁定态**：边框显示警告色描边加锁图标，删除按钮禁用并提示先解锁。

**右侧抽屉**：大图预览、版本时间线（纵向时间轴，可回滚）、引用镜头列表（点击跳转到对应镜头）。

**上传区**：支持拖拽多文件，上传中显示单文件进度，完成后自动入库并刷新列表。

### 5.4 页面四：项目详情 - 剧本

**布局**：左右分栏，左 40% 原文编辑，右 60% 解析结果。

**左侧**：Markdown 编辑器，支持纯文本粘贴，顶部显示字数统计。

**右侧**

| 区块 | 内容 |
| --- | --- |
| 角色区 | 卡片列表，含名称、描述、关联定妆图缩略图；支持合并重复角色 |
| 道具区 | 卡片列表，含名称、描述、锚定图状态；未生成时提供『生成锚定图』按钮（提交后任务中心看进度，成功回写 anchor_asset_id） |
| 场景区 | 折叠列表，每个场景显示序号、标题、镜头数，可展开查看镜头概要 |

**联动**：点击右侧某个场景时，左侧对应原文段落高亮滚动定位。

**出口（单一出口）**：解析完成后展示摘要卡片（场景/角色/道具数量 + 就绪状态），主按钮『去资产库 →』；生成参考图入口不在本页（已迁至资产库制作资产区）。

**顶部操作**：解析按钮（主色）、重新解析按钮（有结果后显示，二次确认后生成候选版本，不直接覆盖当前分镜）。候选版本生成后展示与当前版本的差异（新增/变化/删除的镜头与集）；用户确认切换后旧版本标 superseded，产物按新增→pending、变化→redo+旧产物 stale、删除→archived 规则处理（见 API.md parse-versions）；未确认前当前分镜与产物不受影响。

### 5.5 页面五：任务中心

**布局**：顶部统计卡片 + 筛选条 + 任务表格。

**统计卡片**（4 个）：今日成功数、今日失败数、进行中数量、平均耗时。

**筛选条**：状态（全部 / 进行中 / 成功 / 失败 / 已取消）、类型（图像 / 视频 / 语音 / 解析 / 合成）。类型筛选与后端 `job_type` 的映射：图像=`generate_keyframe`，视频=`generate_clip`，语音=`generate_audio` / `generate_bgm` / `generate_sfx`，解析=`parse`，合成=`compose` / `export`。选择某分类时按映射后的 job_type 集合请求 `GET /api/jobs`。

**任务表格列**

| 列 | 内容 |
| --- | --- |
| 类型 | 图标 + 文字 |
| 任务对象 | 项目名 / 镜头号，可点击跳转 |
| 状态 | 状态标签，进行中显示进度条 |
| 耗时 | 已完成为总耗时，进行中为实时计时 |
| 创建时间 | 相对时间，悬停显示绝对时间 |
| 操作 | 重试 / 取消 / 查看指引 |

**展开详情**：参数 JSON（默认折叠）、工作流名称与版本、错误码、错误详情、产物预览缩略图。

**失败行处理差异**：环境类失败显示『重试』主按钮；配置类失败显示『查看指引』文字按钮，点击打开说明弹窗，内含该错误码的常见成因与处理步骤。失败分类的权威分派表见 ARCHITECTURE.md 5.5 节。

### 5.6 页面六：设置

**布局**：左侧二级导航，右侧表单区。

**二级导航**：ComfyUI / 语言模型 / 工作流 / 关于。

**ComfyUI 页**

| 字段 | 控件 | 说明 |
| --- | --- | --- |
| 实例列表 | 可增删行表格 | 每行含 base_url、权重（正整数）、启用开关；未配置时回退单实例 comfyui_base_url |
| 测试全部实例 | 按钮 + 状态区 | 逐实例探测可达性（GET /system_stats），显示连通/失败与耗时；不提交生成任务，不消耗显存 |

**语言模型页**

| 字段 | 控件 | 说明 |
| --- | --- | --- |

**工作流页**：类型 tab 筛选（全部/图片/视频/TTS/BGM/音效）+ 表格列表（名称、类型、标签、版本、更新时间、操作），操作为下载、校验；『+ 新增工作流』按钮弹出上传弹窗（名称、类型、JSON 文件 ≤10MB、设为默认）。内置工作流受保护，前端不提供删除功能。


**关于页**：展示版本号、许可证、文档链接、日志路径与服务健康状态（数据来自 `GET /api/health`）。

### 5.7 页面七：合成与导出

**布局**：上下两区，上部为合成预览与合成记录，下部为导出任务列表。

**合成区**

| 区域 | 内容 |
| --- | --- |
| 顶部工具条 | 集数选择下拉、合成按钮（主色）、合成容差只读展示 |
| 预览播放器 | 居中，ArtPlayer 播放当前合成版本，支持进度拖拽与静音切换 |
| 合成信息 | 合成版本号、总时长、镜头数、合成时间、warnings 标记（如字幕估算时间） |
| 合成记录列表 | 历史合成版本卡片，含版本号、时间、时长、stale 标记；点击切换预览；stale 版本标注『已失效』不可导出 |

**导出区**

| 区域 | 内容 |
| --- | --- |
| 导出按钮 | 基于当前选中合成版本创建导出任务，需二次确认 |
| 导出记录表格 | 列：文件名、格式、大小、状态（排队中/导出中/成功/失败）、创建时间、下载按钮 |

**合成前校验提示**：若存在未审核放行的超容差镜头或缺失产物，合成按钮禁用并悬停提示具体阻塞原因（如『3 个镜头待审核、1 个镜头视频缺失』）。

**导出与合成的关系**：导出必须基于有效的合成版本（非 stale）；合成版本失效时导出按钮禁用并提示『合成版本已失效，请重新合成』。

## 6. 关键交互

**分镜看板**：按场景分组，场景内横向铺镜头卡片。拖拽仅允许同场景内，跨场景拖动禁用。拖动结束后先显示遮罩，服务端确认后再落地，避免乐观更新导致的回滚跳动。

**资产选择器**：全局弹窗，通过依赖注入唤起，避免多层级传参。卡片显示版本与引用次数。

**进度推送**：任务列表用事件流接收推送，卡片内用轮询兜底，两层配合。

**工作流上传**：前端先本地解析，展示参数与输出表格，再提交后端二次校验。校验不通过时定位到具体节点。

**工作流切换**：生成确认弹窗展示自动匹配结果，提供「切换工作流」入口。点击后调用 `GET /api/workflows?workflow_type={workflow_type}` 获取同类型工作流列表，用户选择后传入 `workflow_id` 覆盖自动匹配结果。

## 7. 性能优化

- 列表统一使用缩略图，点开才加载原图；缩略图经 `GET /api/assets/{id}/file?thumb=true` 获取（资产对象 `thumb_url` 字段），缩略图缺失时回退原文件 `url`
- 可视区外图片懒加载
- 视频卡片只预加载元数据，点击才播
- 资产列表分页，每页 20 条
- 重新生成的图片地址追加版本参数，避免浏览器缓存旧图
- 分镜看板按场景分批加载：先取场景列表，展开某场景时再拉该场景的镜头，避免一次性返回全部镜头（镜头数超过 100 的项目，必须使用 `include_shots=false`，见 API.md）

## 8. 响应式适配

| 视口宽度 | 适配策略 |
| --- | --- |
| ≥1440px | 完整三栏布局 |
| 1024–1439px | 左侧栏折叠为纯图标，主内容区与抽屉保持 |
| <1024px | 左侧栏改为抽屉式唤起，右侧抽屉全屏覆盖 |

最低支持分辨率 1280×800；更窄视口不保证可用，不为此单独适配。

**高度适配**：主内容区最小高度按 `calc(100vh - 56px)` 计算（56px 为顶栏高度）；视口高度低于 800px 时主内容区内部出现纵向滚动，顶栏始终固定不滚动。

**资产库分类树**：≥1440px 时分类树固定 200px 与全局左侧栏并存；1024–1439px 时分类树折叠为图标列（48px），悬停展开浮层；<1024px 时分类树收进资产库页面顶部水平滚动条。

**镜头卡片尺寸**：分镜看板镜头卡片固定 220×320，不随视口缩放；窄视口下靠组内横向滚动承载，不缩小卡片。

## 9. 交互细节规范

| 场景 | 规范 |
| --- | --- |
| 加载态 | 异步操作超过 300ms 显示加载态，超过 3s 显示当前阶段说明文字 |
| 列表空态 | 必须有引导文案与引导按钮，不允许只显示空白 |
| 破坏性操作 | 按钮使用危险色文字并置于次要位置，主按钮始终为安全操作 |
| 错误提示 | 分『可重试』与『需处理』两类，前者带重试按钮，后者带指引链接 |
| 弹窗关闭 | 有未保存修改时二次确认 |
| 长文本 | 截断后悬停展开，禁止出现滚动条嵌套 |
| 按钮禁用 | 必须给出禁用原因（悬停提示），不允许无理由置灰 |
| 状态刷新 | 任务状态变更 2 秒内反映到界面，超时降级为轮询 |
