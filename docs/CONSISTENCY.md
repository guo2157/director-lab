# CONSISTENCY —— 跨镜头一致性方案（唯一权威源）

> 本文档是一致性锚定、度量与失效传播的唯一权威定义。资产与分镜的层级划分见 DATABASE.md，镜头状态与失效标记的语义见 ARCHITECTURE.md。

## 1. 四层锚定（P0）

| 层级 | 产物 | 约束方式 |
| --- | --- | --- |
| 第一层 | 角色定妆图 | 人工确认后锁定为 character 资产 |
| 第二层 | 场景基准图 | 人工确认后锁定为 scene 资产 |
| 第三层 | 分镜图 | 以定妆图与基准图作为参考图传入，配合 IPAdapter 或 FaceID 节点 |
| 第四层 | 视频 | 以分镜图为首帧，天然继承一致性 |

### 1.1 定妆图单图约定

角色定妆图只保留一张，`character.portrait_asset_id` 为单值，不做正侧背三视图。

| 项 | 约定 |
| --- | --- |
| 数量 | 每个角色一张，锁定后为该角色唯一形象来源 |
| 取景 | 四分之三侧角度，胸部以上，人脸占画面比例尽量大 |
| 背景 | 简洁中性背景，不放场景元素，避免与场景基准图互相干扰 |
| 光线 | 均匀柔和的主光，不做过强戏剧光比，防止面部特征被阴影吞掉 |
| 姿态 | 自然站姿或半身正面偏侧，双手不做复杂动作，减少手部畸形 |

不做三视图的理由：
1. 参考图槽位 `ref_identity` 一次只注入一张，多出的角度下游消费不了
2. 一张图内并排多个角度会摊薄人脸像素，一致性评分反而下降，且模型易误把并排构图当成画面内容模仿
3. 拆成三张独立资产需改动 `portrait_asset_id` 类型、槽位注入方式与工作流节点，而多数镜头为正脸或四分之三侧，投入产出不划算

若个别镜头确实需要侧面或背面形象，不修改主定妆图，另建普通 character 类型资产并以 `@角色名侧`、`@角色名背` 命名，在该镜头参考素材中显式引用即可，不影响主链路与既有评分基线。

## 2. 一致性度量（P0）

每个分镜图生成后可计算人物身份相似度；如具备相应检测能力，再分别计算服装/外观、场景、关键道具和镜头连续性指标。各维度独立输出评分与结论（通过 / 待复核 / 不通过 / 未评估）。这些分数仅用于排序与辅助审核，不代表视觉一致性保证，也不得在检测缺失时默认显示高分。

度量模块独立实现，阈值可配置，不混入生成逻辑。每项指标必须记录检测器版本、参考资产版本、适用条件和失败原因；未支持的维度显示『未评估』。

### 2.1 双阈值判定

评分范围为 0–1，采用两个阈值切出三档结论：

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| consistency_pass_threshold | 0.85 | 评分大于等于该值判定为通过 |
| consistency_fail_threshold | 0.70 | 评分小于该值判定为不通过 |

判定规则：

| 评分区间 | verdict | 界面表现 |
| --- | --- | --- |
| 大于等于 pass_threshold | passed | 正常显示 |
| 大于等于 fail_threshold 且小于 pass_threshold | review | 黄色标记，提示人工复核 |
| 小于 fail_threshold | failed | 红色标记，提示重做 |

约束：fail_threshold 必须小于 pass_threshold，保存设置时校验，不满足返回 400 `invalid_request`。两个阈值均可在项目 settings 中覆盖系统默认值。

## 3. 返工策略（P0）

- 单镜重做：只影响该镜头的分镜图与视频
- 场景重做：影响该场景全部镜头，需二次确认
- 角色重做：列出所有引用该角色的镜头，由用户勾选范围
- 版本回滚：恢复旧版资产后，相关镜头标记为待重新生成，不自动执行

## 4. 产物失效传播矩阵（P0）

修改上游数据会使下游产物失效，失效首先将受影响产物标记为 `stale`，镜头可派生显示 `redo`；不自动触发生成，由用户确认后手动发起。逻辑失效与物理删除分离，历史产物保留。

| 触发变更 | 失效产物 | 标记范围 |
| --- | --- | --- |
| 修改 shot.image_prompt | 该镜头分镜图、视频及下游合成 | 本镜头 |
| 修改角色/场景/道具 description 或 appearance | 依赖该描述生成的锚定图、分镜图、视频与合成 | 显式引用该实体的镜头 |
| 更新角色定妆图/场景基准图/道具锚定图 | 依赖旧资产版本的分镜图、视频与合成 | 引用旧版本的镜头 |
| 修改工作流定义或模型能力版本 | 不改写既有产物；新任务使用新版本，旧产物标记为历史/待审核 | 新版本任务及显式选择重做的镜头 |
| 修改 shot.video_prompt | 该镜头视频 | 本镜头 |
| 修改 shot.dialogue | 该镜头视频中的对白/音频质量判定、必要时的 TTS 补救音频、合成成片 | 本镜头；是否重生成视频由用户确认 |
| 修改 shot.duration | 该镜头视频、H3 时长/帧数规划、音频校验及合成成片 | 本镜头 |
| 修改 shot.emotion / soundscape / bgm | 该镜头视频/音频提示词及检查结果；若需 TTS 补救则使补救音频失效 | 本镜头 |
| 修改 shot.shot_type / camera_angle / camera_movement / transition / shot_purpose | 该镜头分镜图、视频 | 本镜头 |
| 资产回滚到旧版本 | 所有引用该资产的镜头的分镜图、视频 | 引用该资产的镜头 |
| 资产解锁后重新生成新版本 | 所有引用该资产的镜头的分镜图、视频 | 引用该资产的镜头 |
| 修改角色音色 voice_id | 引用该角色的镜头配音 | 经由镜头角色关联的镜头 |
| 修改 shot.start_state / end_state | 该镜头视频、同一集内下一镜头视频 | 本镜头及 seq+1 镜头 |
| 某镜头视频重生成导致末帧资产更新 | 同一集内下一镜头视频 | 引用该末帧作为 ref_prev_frame 的镜头 |
| 锁定或删除某镜头末帧资产 | 同一集内下一镜头视频 | 引用该末帧的镜头 |
| 修改项目画幅比 | 全部镜头的分镜图、视频、合成成片 | 全项目 |
| 修改字幕/音轨时间线或 BGM/SFX 编排 | 合成成片；若音频源素材未变则不失效视频 | 对应集/场景/镜头范围 |
| 修改项目一致性阈值 | 不使产物失效，仅重新计算 verdict | 不标记 redo |

### 4.1 级联说明

合成成片依赖全部镜头的视频及按 `shot_kind` 判定的有效对白/旁白音频。音频优先来自 H3 VA 视频音轨，TTS 仅作为补救；任一必需产物失效时，已生成的成片记录标记为过期，重新合成时创建新的 composition 版本，不覆盖历史记录。
