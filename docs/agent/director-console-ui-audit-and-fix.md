## 2. 三栏最终职责定义

- **左栏（260px，可折叠）**：会话导航——新建、搜索（标题过滤）、切换、重命名（双击）、归档。仅显示标题与时间，不展示项目概况/任务/资产。
- **中栏（flex:1，min-width 520px）**：对话与执行主区——消息历史、输入框、模型选择器（唯一展示位置）。视觉焦点：最大空间、消息气泡层级（user 右侧主色底/assistant 左侧中性底）。
- **右栏（300px，可折叠）**：当前会话关联项目的任务上下文——项目概览（名称/状态/阶段/镜头进度）、最近 8 条真实任务（类型/状态/错误码）、项目页跳转入口（分镜看板/资产库/合成导出）、取消关联。随会话切换自动同步（watch project_id）；无关联显示空状态。

## 3. 实际修改文件与关键改动

仅 `frontend/src/views/DirectorConsoleView.vue`（整体重写，无其他文件改动）：

- script：新增 sessionsCollapsed/contextCollapsed 折叠状态、searchKeyword 搜索、nearBottom 滚动跟随检测、contextJobs 任务上下文（listJobs 按项目过滤）、linkingMode 按需关联流、goProject 跳转；移除常驻项目列表点击关联逻辑
- template：左栏加搜索框与折叠按钮；中栏头部合并模型选择器（去 NTag）；右栏改为关联项目上下文 + 空状态 + 关联选择器
- style：flex 滚动体系（替换硬编码 max-height）、折叠按钮、归档按钮 hover 显现、任务列表样式、响应式断点调整（1100/960/768px）

## 4. 视觉规范调整

- 字号层级：面板标题 13px/600、会话标题 13px、消息正文 14px/1.6 行高、元信息 11-12px
- 间距统一：面板 gap 10px、内边距 10-14px、列表项 7px 10px
- 减少视觉噪音：归档按钮默认隐藏（hover 显现）、移除消息数与模型 NTag、任务列表无卡片包裹（纯行式布局）
- 滚动：三栏独立滚动（flex + overflow-y:auto），输入区固定底部
