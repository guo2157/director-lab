# 分镜道具约束提示词模板（prop_continuity_prompt）

分镜图生成前，由后端根据当前镜头的道具生命周期状态（prop_shot_state）自动组装提示词段落。
代码读取本模板的规则结构，注入状态数据后拼装，不硬编码任何具体道具名称。

## 一、道具可见（visible）

- 必须传入道具参考图（@道具名 → anchor_asset_id 对应资产文件）
- 明确道具在画面中的位置（position 字段）
- 明确道具与角色的交互关系（held=手持 / carried=携带 / placed=放置于某处）
- 强制保持资产库外观：颜色、形状、材质、大小、关键特征与定妆图一致
- 不允许随意增加其他道具
