# Director-Lab 项目解说视频

本目录存放 Director-Lab 的中文解说演示视频及其配套素材。画面全部来自本地运行中的真实产品页面与真实生成结果（示例项目《游乐场》），未使用示意图或伪造界面。

## 文件清单

| 文件 | 说明 |
| --- | --- |
| `director-lab-intro.mp4` | 成片，1920×1080 / 30fps / H.264 + AAC，约 4 分 33 秒，含中文配音与烧录字幕 |
| `director-lab-intro.srt` | 简体中文字幕，与配音逐句对齐 |
| `director-lab-script.md` | 完整解说脚本：分段总览、分镜、操作、旁白 |
| `director-lab-cover.png` | 封面图（1920×1080） |
| `recording/` | 各功能模块的原始录屏分段（未加字幕） |
| `audio/narration.wav` | 解说人声音轨（48kHz 立体声，-16 LUFS 归一） |

## 内容结构

1. 开场与产品定位（首页、作品列表）
2. 剧本创作与评估（剧本工作台、评估页选集）
3. 剧本解析（场景 / 角色 / 道具 / 分镜统计）
4. AI 资产库（角色定妆图、场景基准图、道具锚定图、音色面板）
5. 分镜图与分镜看板（26 个镜头、参考图与提示词）
6. 任务中心（图像 / 视频 / 语音 / 合成等任务队列）
7. 合成与导出（视频预览、合成设置、合成记录、导出记录）
8. 模型配置（ComfyUI 多实例、语言模型）
9. AI 导演台与系列管理
10. 最终成片片段 + 片尾

## 制作方式

- 录屏：Edge headless（Puppeteer）在 1920×1080 视口逐帧截图，按脚本时间轴采样到 30fps。
- 配音：Microsoft Edge TTS `zh-CN-XiaoxiaoNeural`（语速 +15%），按句合成后按采样级拼接，保证与字幕严格同步。
- 剪辑：FFmpeg 拼接分段、生成片头片尾卡片、ASS/SRT 字幕烧录（libass）、响度归一（-16 LUFS，True Peak -1.5 dBFS）。
- 最终成片片段：取自项目已合成的《游乐场》成片文件。

## 说明与已知限制

- 视频没有背景音乐轨：仓库内没有可商用/可再分发的 BGM 素材，为避免版权问题只保留了解说人声。
- 设置页中的 ComfyUI 与语言模型服务地址已在画面上打码处理。
- 解说配音使用 Edge TTS 生成，与产品内 TTS 模块无关；产品内的角色配音与最终混音结果体现在片尾成片片段中。
- 音乐、音效、字幕样式等能力以产品当前实现为准，未在视频中展示未上线的规划功能。
