## 1. 阶段划分（按依赖关系排序）

### 阶段 1：项目基础设施与配置（状态：开发中）

- 目标：建立可运行的后端骨架（FastAPI + SQLite + WAL + Alembic）、前端骨架（Vue3 + TS + Vite + Naive UI + Pinia + TanStack Query）、统一配置与启动脚本
- 需求对应：DEVELOPMENT.md 全部；AGENTS.md §3 硬约束 2（技术选型）
- 范围：后端 pyproject/依赖、FastAPI 入口、配置模块（ComfyUI 地址、存储路径、双阈值等 TBD 项全部走配置）；前端 vite 工程、路由、请求封装、错误处理
- 依赖：无（首个阶段）
- 验收标准：后端 uvicorn 启动返回健康检查 200；前端 vite build 成功、dev 启动可访问；Alembic 可执行 upgrade head（空库）
- 测试方案：启动冒烟 + 健康检查接口断言 + 前端构建产物存在性
- 风险：依赖版本兼容性（SQLAlchemy 2.0 / Pydantic v2）；前置条件：无

### 阶段 2：数据库模型与迁移（状态：待开始）

- 目标：按 DATABASE.md 实现全部实体模型、枚举、索引、唯一约束与首个 Alembic 迁移
- 需求对应：DATABASE.md 全量；AGENTS.md §3 硬约束 6（三套枚举禁止混用）、4（迁移必须 downgrade）
- 范围：项目/场景/镜头/角色/道具/资产/任务/工作流/事件 outbox 等全部表；四套状态机字段；ID 前缀规则（prj_/scn_/sht_/chr_/prp_/ast_/job_/wf_）
- 依赖：阶段 1
- 验收标准：迁移 upgrade/downgrade 双向可执行；枚举取值与文档一致；关键唯一约束与索引经 SQLite 实际验证
- 测试方案：迁移测试 + 模型层单元测试（枚举赋值、约束冲突）
- 风险：状态机字段遗漏；前置条件：DATABASE.md 已终审

### 阶段 3：后端核心业务服务与 API（状态：待开始）

- 目标：实现 M1 项目/剧本、M2 角色资产、M3 分镜的全部 API（不含生成），含统一错误格式、幂等、事务纪律
- 需求对应：PRD.md M1–M3；API.md 对应章节；AGENTS.md §3 硬约束 4/5（事务与事件纪律）
- 范围：项目 CRUD、剧本解析接入（PROMPTS.md LLM 层）、角色/道具资产管理、分镜编辑；outbox 事件写入与 event_seq
- 依赖：阶段 2
- 验收标准：API.md 中 M1–M3 全部接口契约测试通过；错误格式统一；重复创建幂等
- 测试方案：接口集成测试（httpx + 临时 SQLite）+ 契约字段比对
- 风险：剧本解析 LLM 外部依赖不可用时需适配器隔离；前置条件：阶段 2 验证通过

### 阶段 4：生成任务编排与 ComfyUI 集成（状态：待开始）

- 目标：实现 M4 任务编排（并发=1、202+SSE、取消/重试/恢复）与 M5 工作流注入、ComfyUI 提交、产物落库
- 需求对应：PRD.md M4/M5；WORKFLOW.md 全文；ARCHITECTURE.md §1/§3；AGENTS.md §3 硬约束 3（并发=1）
- 范围：worker 单实例轮询、工作流参数注入（标记语法 $param/$output）、ComfyUI /prompt 提交与轮询、产物下载与资产关联、失败分类与重试、取消（/interrupt 全局中断警示）、8 份工作流作为种子数据导入
- 依赖：阶段 3
- 验收标准：图像链路（t2i/ref_edit）真实提交 ComfyUI 生成成功并落库；并发=1 经双任务验证；取消/失败重试路径有测试；SSE 事件带递增 event_seq
- 测试方案：集成测试（真实 ComfyUI）+ 失败注入测试（超时/中断/结果保存失败）
- 风险：低显存（AUD3-P1-01）、Qwen3 节点包缺失（AUD3-P0-02）阻塞 TTS 真实联调——TTS 链路先完成适配器与状态管理，真实验证待节点包就位；H3 视频链路同理（AUD3-P2-01）
- 前置条件：阶段 3；ComfyUI 可达

### 阶段 5：前端页面与真实接口联调（状态：待开始）

- 目标：实现 FRONTEND.md 全部页面：项目管理、剧本、分镜板、资产生成与审核、任务队列监控（SSE 实时状态）、设置页（含三方通道区）
- 需求对应：FRONTEND.md 全文；API.md 全量；PRD.md M1–M8 交互
- 范围：全部路由页面、组件、SSE 订阅、加载/空/失败/重复提交状态、刷新后状态恢复
- 依赖：阶段 4（接口先行）
- 验收标准：页面调用的路由全部真实存在；主要操作路径与异常状态覆盖；任务状态实时更新
- 测试方案：组件测试 + 前后端联调冒烟
- 风险：SSE 断线重连；前置条件：阶段 4

### 阶段 6：合成导出与字幕配音（状态：待开始）

- 目标：实现 M6 合成、M7 字幕/配音补救、M8 导出（FFmpeg 合成 MP4）
- 需求对应：PRD.md M6–M8；WORKFLOW.md TTS/BGM 链路；CONSISTENCY.md 失效传播
- 范围：BGM 工作流集成、TTS 补救链路（含 emotion_map 配置化）、句级对齐字幕、FFmpeg 合成队列、导出格式
- 依赖：阶段 4、5
- 验收标准：BGM 真实生成并参与合成；导出 MP4 可播放；失效传播只标记不触发
- 测试方案：合成集成测试 + 导出文件校验（ffprobe）
- 风险：TTS 真实生成依赖节点包；前置条件：阶段 4、5

### 阶段 7：端到端验收（状态：待开始）

- 依赖：阶段 1–6
