# DirectorLab 提示词模板

配套《使用手册》使用。所有 `{}` 内为需要替换的内容。

---

## 一、怎么用

| 模板 | 用在哪 |
| --- | --- |
| 剧本大纲 / 分集 | 剧本工作台，交给语言模型 |
| 分镜表 | 剧本解析前补充要求，或手动写分镜 |
| 角色定妆 / 场景 / 道具 | 资产库，生成图片 |
| 分镜图 | 分镜图环节，逐镜生成 |
| 视频镜头 | 分镜看板，生成视频 |
| 负面词 | 图片/视频工作流的 negative prompt |
| TTS / BGM | 音频环节 |

原则：

1. **资产先立**：角色、场景、道具的视觉描述写死，后面所有镜头复用同一套词。
2. **一镜一动作**：单个镜头只描述一个主要动作，超过两个动作就拆镜。
3. **写可见的东西**：写「右手握兔子玩偶，玩偶左耳有裂口」，不写「她很难过」。
4. **负面词照抄**：不要临时删减，尤其人物相关项。

## 二、剧本与分镜

### 2.1 剧本大纲（单集）

```
你是短剧编剧。请把下面的素材改成 {时长} 分钟的短剧剧本，{竖屏/横屏}，面向 {目标人群}。

要求：
1. 开场 10 秒内出现冲突或悬念；
2. 全剧 {镜头数} 个镜头左右，对白简短口语化，单句不超过 20 字；
3. 只保留 2-3 个主要场景，人物不超过 4 个；
4. 每 3-4 个镜头安排一次情绪或信息推进；
5. 结尾留一个可续集的钩子。

输出格式：
- 人物表（姓名 / 年龄 / 身份 / 外貌关键特征 / 服装）
- 场景表（名称 / 时间 / 天气 / 关键陈设）
- 分镜表（镜号 / 景别 / 画面内容 / 人物动作 / 台词 / 时长）
```

### 2.2 分集目录（系列）

```
下面是系列的 Bible：
{bible}

请规划 {集数} 集的分集目录。每集输出：集名、一句话梗概、主要场景、情绪曲线、结尾钩子。
要求：各集人物设定与世界观不得偏离 Bible；每集至少推进一条主线，不重复上一集的信息。
```

### 2.3 分镜表补全

```
把这一场拆成分镜，要求：
1. 每个镜头只做一件事，时长 {2-6} 秒；
2. 景别交替：远景/全景交代环境，中景推进动作，近景/特写表达情绪；
3. 同一场景内保持人物左右站位一致；
4. 标出每个镜头需要哪些参考图：角色（谁）、场景（哪个）、道具（哪件）；
5. 不要出现镜头无法表现的内容（如"她想起了十年前"）。
```

## 三、资产提示词

### 3.1 角色定妆图

```
{角色名}，{年龄}岁，{性别}，{身份}。
面部：{脸型}，{眼睛}，{眉毛}，{鼻子}，{肤色}。
发型：{长度/颜色/发型}。
服装：{上装}，{下装}，{鞋}，{配饰}。
表情：中性，平静，看向镜头。
构图：半身正面，居中，纯色浅灰背景，均匀柔光，无阴影遮挡面部。
风格：{统一风格，如 写实电影感 / 国漫厚涂}，高清，皮肤质感自然。

负面词：见 4.1
```

使用要点：

- 一个角色只保留一张「母版」定妆图，后续镜头都以它为准。
- 换装时单独做「角色+服装」变体，不要改脸。

### 3.2 场景基准图

```
{场景名}，{时间}，{天气}，{地点类型}。
空间结构：{前景}，{中景主体}，{背景}。
关键陈设：{物品1}、{物品2}、{物品3}（位置要写清楚）。
光线：{光源方向}，{色温}，{明暗对比}。
氛围：{安静/压抑/热闹}。
构图：{广角/中景}，视线高度约 1.5 米，无人物。
风格：与角色图保持一致。
```

### 3.3 道具锚定图

```
{道具名}，{材质}，{颜色}，{尺寸参考}。
细节：{磨损/缺口/文字/图案}，{可辨认特征}。
视角：正面 3/4 角度，单独放置，浅灰背景，柔和顶光。
要求：细节清晰，无人物，无手部，可放大辨认。
```

> 道具的「可辨认特征」要在后续镜头里复用，比如「左耳有裂口的兔子玩偶」。

## 四、镜头提示词

### 4.1 分镜图

```
{景别}，{机位/角度}。
画面主体：{角色名}，{外貌与服装的固定描述}，{当前动作}。
位置关系：{谁在左/右}，{与道具/场景的距离}。
道具：{道具名}，{状态}，{位置}。
场景：{场景名}，{时间/天气}，{关键陈设}。
光线：{方向与色温}，{明暗}。
构图：{三分法/居中/过肩}，{留白方向}。
风格：{统一风格}，竖屏 9:16，电影感，高清。

负面词：见 5.1
```

### 4.2 视频镜头（H3）

```
镜头运动：{固定 / 缓慢推进 / 轻微手持跟随}。
主体动作：{一个明确动作，如 她把兔子玩偶放进帆布包}。
动作幅度：小，动作在 {2-4} 秒内完成。
首帧：与分镜图一致。
尾帧：{下一镜的起始状态，如 手已收回，人物转向门口}。
表演细节：{呼吸/视线/口型} 自然，不夸张。
画面：保持人物与场景一致，无新增人物。

负面词：见 5.2
```

要点：

- 动作幅度小、时间短，画面更稳。
- 需要连贯时，把「尾帧状态」写成下一镜的「首帧状态」。
- 一镜不要同时写走路 + 说话 + 转身。

## 五、负面词

### 5.1 图片通用

```
低分辨率，模糊，噪点，过曝，欠曝，畸变，多余手指，断肢，
脸部变形，五官不对称，双头，多头，重复人物，文字水印，
logo，边框，画中画，塑料感，过度锐化
```

### 5.2 人物专用（追加）

```
换脸，脸型不一致，年龄不符，发型改变，服装变化，妆感过重，
皮肤过白，眼睛大小不一，牙齿畸形，脖子过长
```

### 5.3 场景专用（追加）

```
透视错误，地平线倾斜，物体悬浮，光源矛盾，接缝，重复图案，
现代物品（古装场景时），人物残影
```

### 5.4 道具专用（追加）

```
形状改变，颜色改变，材质错误，比例失调，多件堆叠，手部遮挡
```

### 5.5 视频专用（追加）

```
闪烁，跳帧，画面撕裂，人物突然变形，肢体穿模，背景漂移，
口型与台词不符，镜头剧烈抖动，画面突变，突然出现/消失的人物
```

## 六、音频配置建议

### 6.1 TTS 台词

- 每个角色绑定一个固定音色，全剧不再更换。
- 台词按句切分，单条不超过 20 字，便于对齐。
- 语速先按默认，情绪靠标点和短句体现，不靠夸张语调。

### 6.2 BGM

```
风格：{悬疑/温情/电子}
情绪：{紧张→释然}
速度：{慢/中}，无强人声，无人声采样
时长：{与成片一致}
```

- 成片用 BGM 音量压低（约 -18 到 -22 dB），避免盖住台词。
- 需要段落变化时，按场景切分多段 BGM，不要一首铺全片。

## 七、一致性检查清单

生成完一集后逐条过一遍：

- [ ] 同一角色在不同镜头里，脸型、发型、服装一致
- [ ] 道具的裂口/图案/颜色在每个出现镜头里一致
- [ ] 场景的关键陈设在前后镜头位置一致
- [ ] 人物左右站位符合对话关系
- [ ] 上一镜尾帧与下一镜首帧能接上
- [ ] 镜头总时长与台词长度匹配，没有明显空镜
- [ ] 字幕与人名、标点一致
