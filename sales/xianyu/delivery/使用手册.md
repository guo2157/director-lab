# DirectorLab 使用手册

适用版本：Windows 单文件版 `DirectorLab.exe`（Windows 10 / 11，64 位）

---

## 一、交付内容

购买后你会拿到一个压缩包，解压后应包含：

| 文件 | 说明 |
| --- | --- |
| `DirectorLab.exe` | 主程序，双击运行，浏览器里操作 |
| `使用手册.md` | 本文件 |
| `提示词模板.md` | 角色、场景、道具、分镜、视频的可复用提示词 |

程序为单文件，不需要安装 Python、Node.js 或 ffmpeg。

---

## 二、先确认运行环境

DirectorLab 负责「把流程串起来」，画面和视频的生成需要两个外部服务：

1. **ComfyUI**：本机显卡（建议 12G 显存以上）或云 GPU（AutoDL / CloudStudio 等）。
2. **大模型接口**：通义 / DeepSeek / OpenAI / Ollama 任选，按量付费。

没有显卡也能用：走云 GPU，按小时计费，典型一条 2 分钟短片约 1-4 元算力。

> 只打开软件、写剧本、看界面不联网也能用；生成画面和视频必须能连上上面两个服务。

---

## 三、启动

1. 双击 `DirectorLab.exe`。
2. 程序会在本机启动服务，并自动打开浏览器。
3. 首次启动会在 `%APPDATA%\DirectorLab` 下创建数据库和媒体目录（截图、分镜图、视频、成片都存在这里）。
4. 未配置 ComfyUI 时，页面会自动进入「设置」。

启动失败的排查：

- 端口被占用：先关掉其他占用 8000 端口的程序，再重新双击。
- 浏览器没自动打开：手动访问窗口里提示的地址（默认 `http://127.0.0.1:8000`）。
- 想看到日志：在命令行里执行 `set DLAB_DESKTOP_CONSOLE=1` 后再运行 exe，会保留控制台窗口。

---

## 四、首次配置（只做一次）

进入左侧「设置」。

### 4.1 ComfyUI 实例

1. 点「新增实例」。
2. 实例地址填 ComfyUI 的地址，例如本机 `http://127.0.0.1:8188`，云 GPU 填平台提供的公网地址。
3. 权重填 `1` 即可；有多个实例时，权重越大分到的任务越多。
4. 勾选「启用」，保存后点「测试」，显示成功即连通。

多台机器可以都加进来，系统会按权重和负载做实例池调度。

### 4.2 语言模型

1. 切到「语言模型」→ 新增模型。
2. 填备注名（如「主力模型」）、提供商、API URL、API Key。
3. 点「查询模型」拉取模型列表，选中后点「测试连接」。

常用配置：

| 提供商 | API URL | 说明 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | 性价比高，剧本解析够用 |
| 通义（DashScope 兼容模式） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 国内直连稳定 |
| OpenAI | `https://api.openai.com/v1` | 需要能访问 |
| Ollama | `http://127.0.0.1:11434/v1` | 本地跑，无需 Key |

> 解析长剧本时上下文消耗较大，建议至少准备一个有较长上下文的模型。

### 4.3 工作流

切到「工作流」页，确认这五类都有可用工作流：

- 图片（分镜图、角色/场景/道具资产）
- 视频（分镜视频）
- TTS（台词配音）
- BGM（背景音乐）
- 音效（SFX，可选）

缺哪一类，对应环节就无法生成。模型与工作流需要和你的 ComfyUI 环境匹配（Qwen-Image 2.1、MiniMax H3、Qwen3-TTS、Stable Audio）。环境脚本可参考开箱附带的模型安装脚本（云 GPU 与本机各一份）。

## 五、跑通第一条成片

整体顺序固定：**剧本 → 评估 → 解析 → 资产 → 分镜图 → 分镜视频 → 音频 → 合成导出**。
页面顶部的流程导航会显示每一步状态，完成会打勾。

### 5.1 新建项目

首页「新建项目」，填项目名、画幅（竖屏 9:16 / 横屏 16:9）、风格设定，保存。

### 5.2 剧本

进入「剧本工作台」：

- 直接粘贴小说、大纲或自己写的剧本；
- 也可以先导入再分步补充创作配置（题材、节奏、镜头密度等）。

建议第一次用 1-2 分钟、20-30 个镜头的小剧本练手。

### 5.3 剧本评估

点「评估」，模型会给出结构、节奏、可行性建议。不满意可以直接改剧本再评。
评估不是必做项，但能明显减少后面返工。

### 5.4 剧本解析

点「解析」，系统会一次性产出：

- 分集、场景
- 角色、道具
- 分镜表（景别、时长、动作、站位、对白）
- 音频规划（对白 / 旁白 / BGM / 音效）

解析完成后先看分镜数量和角色是否齐全，再往下走。

### 5.5 资产库（关键步骤）

角色定妆图、场景基准图、道具锚定图都在这里生成。

1. 点「批量生成」或逐个生成。
2. 逐张审核：人物脸型、发型、服装、场景氛围是否符合设定。
3. 不满意就「重新生成」该张，不要将就。

> 这一步决定了后面所有镜头的一致性。角色图没定下来，后面分镜会一直崩脸。

### 5.6 分镜图

1. 确认公共资产都已通过审核。
2. 点「批量生成分镜图」，系统会按分镜表逐镜生成，并自动绑定角色/场景/道具参考图。
3. 逐镜检查：构图、动作、道具位置、人物是否同一人。
4. 单镜不满意可只重生成这一镜。

### 5.7 分镜看板（分镜视频）

1. 进入分镜看板，确认每个镜头的提示词、时长、参考图职责。
2. 点「生成视频」。视频按镜头序号串行生成，上一镜尾帧会自动成为下一镜首帧。
3. 某镜失败会级联取消后面的镜头，避免带着错误参数继续生成；修好后从失败镜头继续。

生成时间与显卡相关，26 个镜头的示例项目在中端显卡上通常需要数小时，建议挂着跑。

### 5.8 配音与音频

- 在角色资产里绑定音色（Qwen3-TTS，可克隆）。
- 生成台词配音、BGM、必要音效。
- 视频原生音轨与 TTS 是解耦的，可按策略保留或丢弃，最终在合成阶段混音。

### 5.9 合成导出

1. 进入「合成导出」，检查镜头顺序、字幕、音轨。
2. 点「合成」，FFmpeg 会完成拼接、混音、字幕烧录、时长对齐。
3. 成片可在页面预览和下载，默认输出竖屏 1080P MP4。

## 六、系列模式（多集连续剧）

系列用于「一次设定人物和世界观，后续每集续写」。

1. 新建系列，填 Bible（人物、世界观、风格、禁忌）。
2. 新建剧集 → 续写生成剧本 → 绑定到生产项目。
3. 每集走完上面的单集流程。
4. 系列会维护剧情事实与连续性状态，续写时自动带上前面剧集的关键信息。

当前版本：单集生产仍在项目工作台完成，系列负责设定、剧集管理和续写。

---

## 七、数据与备份

- 数据目录：`%APPDATA%\DirectorLab`
- 数据库：目录下的 SQLite 文件
- 媒体：分镜图、视频、音频、成片都在该目录内

换机器或重装系统前，整目录复制即可迁移。
建议每个项目导出成片后单独留存，避免磁盘占满。

## 八、常见问题

**Q：双击后窗口闪退 / 打不开页面**
端口被占用或杀毒软件拦截。先确认没有其他程序占 8000 端口，必要时把 exe 加入白名单，再重试。

**Q：任务一直排队不动**
确认后台 worker 在运行（推荐用 exe 启动，会一起拉起）。若手动起服务，需要同时启动调度进程。

**Q：提示 database is locked**
并发写库冲突。确保只有一个实例在跑；本版本已将等待时间放宽到 30 秒，正常操作不会再报。

**Q：生成报模型或节点缺失**
ComfyUI 里缺模型/自定义节点，或工作流与模型版本不匹配。先在工作流页核对，再在 ComfyUI 里补装。

**Q：显存不足 / 生成极慢**
降低分辨率或单次生成数量；或改用云 GPU，并把实例地址加到设置里。

**Q：人物在不同镜头长相不一致**
回到资产库，确认角色定妆图已审核通过并被分镜引用；必要时重生成该角色图，再重跑相关分镜。

**Q：视频没有声音 / 配音对不上**
确认音频环节已生成台词配音，并在合成阶段选择了对应音轨；H3 原生音轨与 TTS 是两套来源，按策略二选一或混合。
