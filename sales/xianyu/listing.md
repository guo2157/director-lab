## 五、上架操作建议

1. **类目**：发布时选「软件/服务 → 其他软件」或「技能服务 → 设计/剪辑」。不要选「全新」实物类目，避免被判虚假发货。
2. **发货方式**：拍下后发网盘链接 + 提取码，附一句「先看手册，装环境时随时找我」。
3. **图片顺序**：封面（成片+界面）→ 分镜看板 → 分镜图墙 → 资产库 → 流程图。
4. **定价技巧**：主推 199 套餐，50 做引流款，299 做锚点；闲鱼支持「多规格」，建议直接开三档。
5. **风控提醒**：描述里不要出现「包过」「月入」「代做」「破解」，不要放微信号/二维码；需要私聊引导时用「点击我想要」。
6. **信任背书**：可把 GitHub 仓库地址放在「个人简介」，比口头承诺更有说服力。

## 六、自动回复与自动发货

**前提说明**：闲鱼网页版（goofish.com）没有任何自动回复 / 自动发货入口，只能在手机 APP 里设置；而且平台只允许自动发「一段文字」，不允许自动传文件。所以「自动发送 exe 和文档」的实际做法是：把交付包放网盘，自动发出网盘链接 + 提取码。

### 1. 先准备交付包

`dist_desktop/DirectorLab-免安装版-含手册与模板.zip`（约 194MB，内含 DirectorLab.exe、使用手册.md、提示词模板.md）。

上传到网盘后，把分享链接设成「永久有效 + 需提取码」，不要设 7 天过期，否则买家晚付款会拿不到。

### 2. 自动回复（买家咨询时）

闲鱼 APP → 消息 → 右上角设置 → 自动回复 → 开启「首次咨询自动回复」：

```
在的，软件是 Windows 免安装版，双击就能用（需要自己有 ComfyUI 或云 GPU）。
拍下后会自动发下载链接和使用手册，手把手带跑第一条成片。
拍之前建议先看简介里的「运行环境」那一段，确认你这边能用，避免白花钱。
```

### 3. 自动发货（付款后）

闲鱼 APP → 我卖出的 → 找到该商品 → 自动发货 → 填写发货内容（仅虚拟商品类目才有此入口）：

```
已收到付款，感谢支持。

下载链接：【网盘链接】
提取码：【提取码】

压缩包里是三个文件：
1. DirectorLab.exe —— 双击运行，浏览器会自动打开工作台
2. 使用手册.md —— 先看这一份，从配置 ComfyUI 到导出第一条成片
3. 提示词模板.md —— 角色、场景、道具、分镜、视频和负面词，可直接套用

建议按手册第四节「首次配置」走一遍，跑不通随时在这里找我，7 天内一对一答疑。
```

### 4. 发货后追问时

```
解压后先看《使用手册》第三节「启动」：双击 exe，数据会存在 %APPDATA%\DirectorLab。
如果窗口闪退，用命令行加 DLAB_DESKTOP_CONSOLE=1 再启动一次，会打印报错原因，把报错发我。
```

### 5. 注意事项

- 自动发货内容里**不要**放微信号、二维码、手机号，容易被判引导站外交易。
- 如果 APP 里找不到「自动发货」入口，说明当前商品不在虚拟自动发货类目：此时用「文案 A 自动回复 + 手动发文案 B」，拍下后复制粘贴即可，成本很低。
- 自动回复只是兜底，别写成「已自动发货」——真实发货仍以你发出的链接为准。
